# Liar's Table
Liar's Table was my first game I ever made, initially released on October 30th, 2024. After existing for nearly a year, it unfortunately was taken down on September 25th, 2025. I put thousands of hours into this game. It was my first - and at the time of writing this, my biggest - success on Roblox, gaining over 66 million visits before it's unfortunate end. I miss it dearly, but I hope it can live on through this repository and at least be used as a tool for better, newer games.

The game's code isn't anything crazy. It's honestly embarrassing to showcase, because I know I can do a lot better, but it's my first success, so take that as you will. Don't expect any top-level coding from this game.

# Use
You can download the [liarstable.rblx](https://github.com/peterron03/liarstable/blob/main/liarstable.rbxl) file and edit it via Roblox Studio if you'd like.

You're free to use it for your own projects, I don't really care all that much, just don't claim it as your own.

[rbxlx-to-rojo](https://github.com/rojo-rbx/rbxlx-to-rojo) was used to extract the source code, which can be seen under the `src` folder.
